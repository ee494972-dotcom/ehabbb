## 🔍 خوارزميات الكشف

### 1. كشف تغيرات الحركة الحادة

```
المنطق:
  إذا كان اللاعب يغير اتجاهه فجأة نحو أهداف جديدة
  ولم يكن يستطيع رؤيتهم قبلاً
  → يستخدم ESP محتملاً

المثال:
  الهدف 1: مسافة 200م
  الهدف 2: مسافة 3000م (غير مرئي عادةً)
  → التوجه فجأة نحو الهدف 2
  ⚠️ تحذير: محتمل ESP
```

### 2. كشف شذوذ المسافات

```
المنطق:
  إذا كان الهدف مرئياً على الشاشة
  لكن على مسافة أكثر من الحد الطبيعي للرؤية
  → قد يستخدم عرض بعيد المدى بشكل غير طبيعي

القيم:
  • المسافة الطبيعية: 100-1000م
  • مسافة مريبة: 1000-3000م
  • مسافة شاذة: > 3000م
```

### 3. كشف الرؤية المستحيلة

```
المنطق:
  إذا كان الهدف خلف جدران أو عوائق
  لكن لا يزال "مرئياً" على الشاشة
  → يستخدم Wall Hacks أو ESP متقدم

التحقق:
  • استخدم raycasting للتحقق من الرؤية الفعلية
  • قارن مع الموقع على الشاشة
  • تحقق من الرؤية المباشرة
```

### 4. كشف الزوايا الشاذة

```
المنطق:
  إذا كان اللاعب يستهدف أهداف غير مرئية
  بدقة غير طبيعية (زوايا مستحيلة)
  → يستخدم Aimbot + ESP

المثال:
  • هدف خلف جدار يبعد 2000م
  • اللاعب يوجه نحوه برقة عالية
  ⚠️ احتمالية عالية لاستخدام cheats
```

## ❓ أسئلة شائعة

### س: كيف أجد العناوين الصحيحة؟
**ج:** استخدم Cheat Engine:
1. افتح Cheat Engine
2. اختر عملية اللعبة/المحاكي
3. ابحث عن الـ signature: `48 8B 0D ? ? ? ?`
4. احسب العنوان من RIP-relative offset

### س: هل هذا آمن قانونياً؟
**ج:** نعم، طالما تستخدمه على:
- لعبتك الخاصة
- بيئة تطوير آمنة
- لاختبار نظام الأمان الخاص بك

### س: كيف أزيد من دقة الكشف؟
**ج:** 
- أضف خوارزميات كشف جديدة
- استخدم Machine Learning
- حلل السلوك عبر الزمن
- استخدم Network Traffic Analysis

### س: ماذا إذا تغيرت العناوين بعد تحديث؟
**ج:**
- أعد البحث باستخدام Cheat Engine
- استخدم `auto_update_offsets` في الإعدادات
- استخدم signature-based scanning

### س: هل أحتاج صلاحيات Admin؟
**ج:** نعم، لقراءة ذاكرة عملية أخرى تحتاج إلى:
- تشغيل البرنامج كـ Administrator
- أو تثبيت kernel driver (متقدم)
